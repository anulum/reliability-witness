# Decision: independently account for laboratory reliability observations

## Context

Elapsed wall time, sampled voter flags and model fault injection do not by themselves measure physical event rates. Unknown observation coverage, repeated disagreement and unqualified inference can create unjustified guarantees.

## Decision

Reliability Witness owns bounded laboratory observation, durable joint event and coverage records, independent accounting, qualified analysis and reports. SC-NeuroCore retains actual designs and mitigation. Loop Timing Witness supplies admitted capture and timebase; Evidence Manifest Toolkit supplies shared evidence operations. Flight Recorder owns field attestation. Studio renders existing findings.

## Consequences

Repository tooling can be qualified before a soak runner exists. Actual workload, observer, device, clock, stopping, statistical and numerical admission remain mandatory. Zero observed events never establish a zero underlying rate. Physical and independent qualification need their own actual evidence.
