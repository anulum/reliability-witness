# Roadmap

## Current foundation

Repository identity, legal texts, architecture, governance, native documentation and dedicated validation tools are being qualified. Domain capabilities and claims remain empty.

## Capability milestones

Admit complete source-bound SC and SNN workloads, TMR variants, actual devices, observer, calibration, timebase, conditions and stopping plan. Implement bounded soak start and identified segment resume with jointly durable event, coverage, condition and checkpoint records.

Independent accounting must reconstruct disjoint device exposure and event classes. Qualified inference needs actual event-law admission, validated numerical bounds and conservative physical uncertainty. Complete all drift and prior-budget branches, full reports through shared evidence operations, independent installed consumers and Studio rendering.

Actual fabric observations and independent reproduction require real hardware, sensor, clock and protocol acceptance. Each implemented language and boundary includes native quality, meaningful coverage, counterpart parity and affected benchmarks from its first change. Public activation and release require separate evidence; no availability date or reliability advantage is promised.
