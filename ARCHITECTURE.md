# Architecture

## Current executable surface

Repository validation tooling, dedicated tests, workflow definitions and native documentation are implemented. No soak runner, observation journal, event analyser, numerical backend, report or product command is installed. Domain capability, claim and qualified-format inventories remain empty.

## Intended data flow

A prior complete workload, device, observation, condition, clock and stopping plan admits acquisition. Raw events, observed windows, gaps, conditions and checkpoint commit together. Independent analysis reconstructs exact exposure and event classes before qualified inference, drift and budget interpretation. Full reports use installed shared evidence operations; separate consumers verify the same immutable scope. Studio renders existing findings.

## Ownership

Reliability Witness owns laboratory scheduling, durable observation, accounting, analysis and report. SC-NeuroCore owns actual designs and TMR mitigation. Loop Timing Witness owns admitted capture, timebase and instrument interfaces; Evidence Manifest Toolkit owns shared evidence operations. Field attestation belongs to Flight Recorder. Safety and deployment consumers retain exact laboratory limits.

## Interpretation

A combinational voter flag is not a persistent event counter. Unknown detection coverage, unobserved intervals and unqualified clock or numerical inputs cannot become event-free exposure or a positive guarantee. Recorded conditions do not imply controlled conditions. Read [the documentation architecture](docs/ARCHITECTURE.md) for full boundaries.
